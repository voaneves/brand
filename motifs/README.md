# motifs

Decorative SVG waves, kept in the repository (not part of the npm package; all rights reserved with the logo, see `LICENSES.md`).

- `services_wave.svg`: section divider above or below the services block.
- `timeline_wave.svg`: structural wave for the career timeline.

Use as `<img alt="" src=...>` or CSS `background-image` (purely decorative, never carry information), and keep them off Sinal surfaces. Colors are fixed in the files; do not recolor.
