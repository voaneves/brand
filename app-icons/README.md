# app-icons

Favicon, touch and PWA icons, shipped as `@voaneves/brand/app-icons/*`.

| File | Use |
|---|---|
| `favicon.svg` | Modern browsers (scalable, the mark) |
| `favicon.ico` | Legacy fallback |
| `apple-touch-icon.png` | iOS home screen (180 px) |
| `icon-192.png`, `icon-512.png` | PWA manifest icons |
| `maskable-512.png` | PWA maskable icon (safe zone inside the disc) |

```html
<link rel="icon" href="/app-icons/favicon.svg" type="image/svg+xml">
<link rel="icon" href="/app-icons/favicon.ico" sizes="32x32">
<link rel="apple-touch-icon" href="/app-icons/apple-touch-icon.png">
```

The disc is the mark from `logo/` (minimum 16 px, see `docs/03-logo.md`). Sources are generated by `npm run build:icons`.
