# 05 — Espaçamento e Layout

O ritmo vertical utiliza múltiplos de `4px` (`--vn-space-1` a `--vn-space-14`) combinados com pausas editoriais nomeadas.

## Aliases de Ritmo

- `--vn-space-beat` (`--vn-space-9`, `64px`): Separação entre blocos relacionados.
- `--vn-space-breath` (`--vn-space-12`, `128px`): Respiro entre seções principais.
- `--vn-space-pause` (`--vn-space-14`, `256px`): Transição de capítulo ou fechamento de página.

## Container e Grid

- **Largura máxima do container (`.vn-container`):** `--vn-layout-container-max` (`1500px`).
- **Medida de leitura (`.vn-measure`):** `--vn-layout-measure` (`640px`).
- **Alvo mínimo de toque:** `--vn-layout-touch-min` (`44px`).
- **Gutters:** `--vn-layout-gutter-sm` (`16px`), `--vn-layout-gutter-md` (`24px`), `--vn-layout-gutter-lg` (`32px`).
