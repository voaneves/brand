# StatusPill (`.vn-status-pill`)

Pílula compacta para indicar disponibilidade imediata sem animação infinita distrativa.

## Anatomia

- `.vn-status-pill`: Contêiner pill com borda sutil (`--vn-line`).
- `.vn-status-pill__dot`: Ponto `8px` em `--vn-status-pill-dot-bg` com pulso finito de `3` ciclos (`--vn-status-pill-pulse-count`, `--vn-status-pill-pulse-duration`).
