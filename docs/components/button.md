# Button (`.vn-btn`)

Botão de ação em formato pill (`--vn-button-radius`) com suporte a variantes `--primary`, `--secondary`, `--signal` e `--ghost`, nos tamanhos `--sm` (`32px`), `--md` (`40px`), `--lg` (`48px`) e `--xl` (`56px`).

## Anatomia

- `.vn-btn`: Contêiner inline flex, tipografia `.vn-type-label`.
- `.vn-btn__dot`: Indicador circular `8px` opcional.

## Tokens Consumidos

`--vn-button-primary-*`, `--vn-button-signal-*`, `--vn-button-secondary-*`, `--vn-button-height-*`, `--vn-button-focus-*`, `--vn-button-scale-active`, `--vn-button-opacity-disabled`.
