# Field (`.vn-field`)

Campo de formulário estruturado com rótulo em mono, borda `--vn-field-border` e estado acessível `aria-invalid="true"`.

## Anatomia

- `.vn-field__label`
- `.vn-field__input` (altura mínima `--vn-button-height-lg`)
- `.vn-field__error` (cor `--vn-signal-ink` com contraste >= 4.5:1)
