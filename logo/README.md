# logo

Canonical brand mark, wordmark, and lockups for Victor Neves / VOANEVES.

Adopted Concept B (Sinal) via [ADR 0004](../docs/decisions/0004-logo-concept-b-sinal.md).

## Files

- `mark.svg`: Standard mark (Tinta disc, Creme V, Sinal dot).
- `mark-reverse.svg`: Reverse mark for dark grounds (Creme disc with cut-out V, Sinal dot).
- `mark-mono.svg`: Single-ink mark (dot punched out as transparent circle).
- `wordmark.svg`, `wordmark-reverse.svg`, `wordmark-mono.svg`: Live-text "VOANEVES." in JetBrains Mono 700 with Sinal dot (ADR 0002).
- `lockup-horizontal.svg`, `lockup-horizontal-reverse.svg`, `lockup-horizontal-mono.svg`: Horizontal lockups.
- `lockup-stacked.svg`: Stacked lockup.
- `signature.svg`: Compact signature mark.

Historical concept explorations and comparison sheet are preserved in [`concepts/`](concepts/).
